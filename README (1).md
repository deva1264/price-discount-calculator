# Price & Discount Calculator – JavaScript Fundamentals

Assignment No. 2 – Week 5, Session 15

A pure JavaScript price calculator (no DOM, no arrays) that prints a full price summary to the browser console.

## Functions
- `calculateDiscountedPrice(price, discount)`
- `calculateTax(price, taxRate)`
- `calculateFinalPrice(price, discount, taxRate)`
- `isFreeShipping(finalPrice)` – Free Shipping at Rs.500 or more, otherwise Rs.49
- `getStockMessage(status)` – uses `switch`

## Run
Open `index.html` in a browser, then open the console (F12 → Console).
